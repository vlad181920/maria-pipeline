# 🌩️ Maria Cloud Node (v1)

Базовий хмарний вузол для Марії.
Використовується для запуску автономних агентів у віддаленому середовищі (VPS, cloud VM, Docker).

## Структура
- src/ — вихідні модулі вузла (mirror частини ядра)
- config/ — конфігурації підключення та середовища
- logs/ — журнали роботи вузла
- artifacts/ — синхронізовані дані й звіти

## Основна мета
- Отримувати оновлення з GitHub.
- Виконувати обрані агенти (brain, reasoner, meta, strategy).
- Повідомляти локальну Марію про стан вузла через sync-канал.
